El objetivo principal del articulo es pronosticar el resultado de un partido para el equipo local, clasificándolo en una de tres opciones: **Victoria, Empate o Derrota**.

Para lograrlo, se implementa una arquitectura híbrida de Deep Learning que combina una Red Convolucional Unidimensional (1D CNN) con bloques residenciales para procesar estadísticas numéricas continuas, junto con capas de Transformador (Transformer) adaptadas para capturar las interacciones y dependencias contextuales de las variables categóricas mediante mecanismos de autoatención. El proyecto está desarrollado completamente en Python y utiliza una metodología de Validación en Ventana Rodante (Rolling Window) para evaluar el modelo cronológicamente de forma iterativa y evitar la filtración de datos (data leakage).
